# 📱 Download APK on Your Phone - Super Quick Guide

## 🎯 Easiest Way (2 Minutes)

Since you're on mobile right now, here's the **absolute fastest** way to get the APK:

---

### **Step 1: Open This Link on Your Phone**

```
https://github.com/YOUR_USERNAME/indieradio/actions
```

Replace `YOUR_USERNAME` with your actual GitHub username.

---

### **Step 2: Find the Latest Build**

You'll see a list with green checkmarks ✅

Tap on the **latest one** (at the top)

---

### **Step 3: Download the APK**

Scroll down to the **"Artifacts"** section (at the bottom)

Tap on **"indieradio-debug-apk"**

A ZIP file will download to your phone

---

### **Step 4: Install**

1. Open your **Files** or **Downloads** app
2. Find the downloaded ZIP file
3. Extract it (long-press → Extract)
4. Tap on **app-debug.apk**
5. If asked, allow "Install from Unknown Sources"
6. Tap **Install**
7. Done! 🎉

---

## ⚡ Wait, There's No Build Yet?

No problem! The build runs automatically whenever code is pushed.

**Or trigger it manually:**

1. Go to: `https://github.com/YOUR_USERNAME/indieradio/actions`
2. Tap **"Build APK"** in the left sidebar
3. Tap **"Run workflow"** button (top right)
4. Tap the green **"Run workflow"** button
5. Wait 3-5 minutes ⏳
6. Refresh the page - you'll see a green checkmark ✅
7. Follow Step 3 above to download

## ❓ Common Issues

### **"I don't see any builds in Actions"**
- Make sure GitHub Actions is enabled:
  - Repo Settings → Actions → General → Enable

### **"Download says 'You must be signed in'"**
- Sign in to GitHub on your mobile browser
- Or use the GitHub mobile app

### **"Can't install - Installation blocked"**
- Settings → Security → Allow "Unknown sources"
- Or Settings → Apps → [Your Browser] → Install unknown apps

### **"ZIP won't extract"**
- Try a different file manager app
- Or use "ZArchiver" from Play Store (free)
